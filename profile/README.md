## What Is PDF OCR X for Mac

PDF OCR X mac is a simple drag-and-drop utility that converts your PDFs into text or searchable PDF
documents. It uses advanced OCR — optical character recognition — to extract the text of a PDF even
when that text is contained in an image rather than as selectable characters. That makes it especially
useful for anything produced by a Scan-to-PDF function in a scanner or photocopier, where the page is
really just a picture of the words.

Because it is built around a single action — drop a PDF, get text — pdf ocr x for mac stays approachable
no matter your technical background. The OCR engine is based on Tesseract, and it supports over 60
languages, including English, French, German, Dutch, Spanish, Portuguese, Basque, Vietnamese and
Italian. The rest of this page looks at exactly who benefits from that and how.
